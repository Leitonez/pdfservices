# Tasks

Verification follows the project's practice: build with `dotnet build` in `api/`, run the local Functions host on port 7215 and exercise the endpoint with a bash + curl script (scratchpad, never committed) using an API key of the dev test account in the `Development` database. Overrides are set on that account by patching its document in the dev database (Cosmos REST or Data Explorer). Test images: public PNG/JPEG over https made distinct with a query string (for example `https://pdfservices.sistema.site/assets/img/og-image.png?n=1..83`); failing URL: a 404 on the same host; slow URL: `https://httpbin.org/delay/<s>`. HTML and PDFs used in tests stay in the scratchpad.

## 3. Total fetch time budget

- [x] 3.1 Add `MaxTotalFetchSeconds` (default 60) to `Html2PdfOptions`. The retriever creates a `CancellationTokenSource` for the budget at the start of the conversion, passes its token to every fetch, and memoizes as refused (without network access) any new URL requested after the deadline. Add a `budgetExhausted` flag to `ConversionResult` and to the summary log line in `Html2PdfFunction` (counters only, never URLs). Verify with `Html2Pdf__MaxTotalFetchSeconds=3` in `local.settings.json`: a document with 5 `https://httpbin.org/delay/2` images plus 1 valid image at the end returns 200 with the PDF in roughly 3–5 s, the slow images and any image after the deadline counted in `X-Blocked-Resources`, and the account charged once.
- [x] 3.2 Verify the repeated failing URL is not fetched again: a document with the same `https://httpbin.org/delay/2` URL 10 times (budget back at 60 s) finishes its fetching in about 2 s, not 20 s, with `X-Blocked-Resources: 1`.
- [x] 3.3 Add `Html2Pdf__MaxTotalFetchSeconds` to the `Html2Pdf__*` row of the settings table in `README.md`, and the budget to the images line of `docs.js` ("até 60 s no total para baixar as imagens"). Verify: README table and panel docs show the new setting and text.
